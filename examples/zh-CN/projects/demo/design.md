# Demo API 设计方案

> 只写现在的方案。带日期的决定和实施记录在[项目日志](log.md)。

## 目标和范围

- 财务不用连库，就能拿到任意日期范围的发票。
- 不做：改发票、给客户直接用。

## 架构

- 一个无状态的 FastAPI 服务，用 `readonly` 用户读 `example_db`。
- `GET /export/invoices?from=&to=&format=json|csv`；导出时把时间转成客户的时区。
