# guides — how-tos and tips

Tool usage, tips and guides you need to remember, kept up to date. Unlike [research](../research/README.md): this is "how to use it", research is "which one to pick".

## Conventions

- Sub-folders per tool or area; single docs start at the root and move into a sub-folder once there are two or three of a kind.
- frontmatter: `type: guide`, `aliases`, `topic` (its sub-folder), `updated` (last update date); the "Guides" view of [overview.base](../../overview.base) shows them all.
