## 约定

- 按工具或领域分子目录；零散的单篇先放根目录，同类攒到两三篇再收进子目录。
- frontmatter 写 `type: guide`、`aliases`、`topic`（所属子目录）、`updated`（最后更新日期），在 [overview.base](../../overview.base) 的「指南」视图里能看到全部。
