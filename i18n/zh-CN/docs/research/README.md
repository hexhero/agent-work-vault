# research — 调研

技术调研和选型对比，是某个时间点的判断，会过时。和 [guides](../guides/README.md) 的区别：这里写「选哪个、为什么」，guides 写「怎么用」。

## 约定

- 按主题分子目录。
- frontmatter 写 `type: research`、`aliases`、`topic`（所属子目录）、`updated`（最后更新日期），在 [overview.base](../../overview.base) 的「调研」视图里能看到全部和更新日期。
- 调研里的数字（star、版本、价格）过时得快，正文写明调研日期，以「去哪查」为准。
